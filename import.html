Employee Data Import

পুরোনো Employee ID Search HTML ফাইল থেকে কর্মচারীদের তথ্য Firestore-এ Import করুন।

গুরুত্বপূর্ণ: এই পেজে পুরোনো HTML ফাইলটি আপনার কম্পিউটার থেকে নির্বাচন করতে হবে। কর্মচারীদের ডেটা এই import.html ফাইলে রাখা নেই; তাই GitHub-এর Public Repository-তে ফোন নম্বর প্রকাশ হবে না।

১. পুরোনো HTML ফাইল নির্বাচন

যে ফাইলে আগের const users = [...] তালিকা আছে, সেটি নির্বাচন করুন।

0সঠিক রেকর্ড
0খালি/অসম্পূর্ণ
0ডুপ্লিকেট ID গ্রুপ

ডুপ্লিকেট ID-র সব রেকর্ড Import থেকে বাদ যাবে। আগে থেকেই Firestore-এ থাকা ID-ও পরিবর্তন করা হবে না।

২. Import-এর নিয়ম

  • Employee ID ও Name না থাকলে রেকর্ড বাদ যাবে।
  • Employee ID এবং Phone নম্বর Text হিসেবেই সংরক্ষিত হবে; শুরুর ০ থাকবে।
  • একই ID একাধিকবার থাকলে সবগুলো বাদ যাবে, যাতে ভুল ব্যক্তির তথ্য মিশে না যায়।
  • আগে থেকে থাকা Employee ID overwrite হবে না।
  • Import সম্পন্ন হলে Dashboard-এ কর্মচারীর তালিকা দেখা যাবে।
